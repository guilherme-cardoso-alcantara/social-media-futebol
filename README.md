# Social Midia Futebol

Aplicativo gratuito para planejar posts de Instagram de uma loja de camisas de time sem expor produtos, escudos, marcas, patrocinadores ou nomes oficiais.

## Como abrir localmente

Abra o arquivo `index.html` no navegador.

## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub.
2. Envie os arquivos deste projeto para o repositório.
3. Abra `Settings`.
4. Entre em `Pages`.
5. Em `Build and deployment`, escolha:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. Salve.

Depois de alguns instantes, o GitHub mostrará o link público do aplicativo.

## Importante sobre os dados

Esta versão salva os dados no navegador de cada computador. Ao publicar no GitHub Pages, o aplicativo ficará acessível por link, mas os dados ainda não sincronizam automaticamente entre computadores.

Para sincronizar tudo entre computadores, a próxima etapa é conectar login e banco de dados gratuito, como Supabase ou Firebase.
